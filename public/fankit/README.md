# FF14 ファンキットのアクションアイコン

- 出典: スクウェア・エニックスが配布している FINAL FANTASY XIV のファンキットのアクションアイコン（「FFXIVIcons Battle(PvE)」）。管理者が提供した zip を展開し、一番上のフォルダ名だけ `battle-pve` に変えて置いた（2026-09-24）。
- 中身: ジョブごとのフォルダ（`01_PLD` など）に、アクションの英語名のファイル（76×76 の PNG。ホットバーの枠・光沢・影が付いている）。`Role_Actions` はロールアクション、`Traits` は特性。
- 使い方: モックは、抽出データの英語名（`name.en`）とファイル名を、どちらも小文字の英数字だけにして突き合わせる（`mock/build-mock-data.mjs`）。見つからないアクション（2026-09 時点で占星術師「ホロスコープ」・賢者「エウダイモニア」）は、抽出したアイコン（`public/icons/actions/`）を使う。
- このフォルダは抽出ツールの出力ではない（`public/icons/` とは別）。差し替えるときは新しい zip の中身で丸ごと置き換える。
