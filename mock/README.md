# UI モック（木人練習: 侍・ナイト・白魔道士 Lv100）

FF14 の HUD に寄せた見た目と操作感を試すための、単独で動くモックです。本実装（React / TypeScript）の前に、見た目と操作感を確かめるためのものです。

## 開き方

`mock/index.html` をブラウザで開くと動きます（`../public/icons/` のアイコンとゲージのテクスチャを参照するので、リポジトリの中で開いてください）。ジョブゲージの光の演出はテクスチャをマスクに使うため、`file://` で開いたときはブラウザによっては出ないことがあります（ローカルの HTTP サーバーか、公開 URL で確認してください）。3D の練習場は WebGL を使います。使えない環境だけ、予備として真上の 2D で表示します。

| 操作 | キー |
|------|------|
| ジョブの切り替え | 開始画面か「設定 → 練習」で選ぶ（ページを読み直す）。URL の `?job=PLD` のようにしても開ける |
| 開始（3 秒カウントダウン） | `Space` / パッドの Start（練習中の `Space` はジャンプ） |
| リセット | `Esc`（設定を開いているときは設定を閉じる） |
| 移動 | 読み込んだ KEYBIND.DAT の移動キー（サンプルは `W` `A` `S` `D`）・矢印キー（カメラに使うものを除く）・パッドの左スティック。「前」はカメラの向き（画面の奥）。マウスの左右同時押しでも前進 |
| カメラ（3D） | マウスの左・右ドラッグで回す、ホイールで近づける・離す。KEYBIND.DAT のカメラ操作（サンプルは `←` `→` で左右、`Ctrl`+`↑` `↓` で上下、`Ctrl`+`Shift`+`End` で自分の後ろへ）。パッドは右スティック |
| ホットバー | 読み込んだ KEYBIND.DAT のとおり。押しっぱなしでは連打にならない（押し直す） |
| クロスホットバー（パッド） | L2/R2 を押しながら十字キー・ボタン |
| 説明文を見る | アイコンにマウスを乗せる（射程・範囲・方向指定も出る） |
| 設定 | 左上の「設定」（開いている間は一時停止） |

## 主な機能

| 機能 | 内容 |
|------|------|
| 3D の練習場（HD-2D 風） | three.js で床・縁・空・明かりを立体で描き、人物と小物はドット絵の板（いつもカメラの方を向く）で立たせる。カメラは回せる（PC 版 FF14 と同じマウス操作）。予兆と敵の足元の輪は床に貼る。光のにじみ・ピントのぼかし（自分と敵のあいだは合わせる）・周辺減光。自分が敵の後ろに隠れると敵を薄くする。画質は 高 / 標準 / 軽い（2D の切り替えはなくした） |
| ジョブ | 侍（近接）・ナイト（タンク）・白魔道士（ヒーラー）。技の共通の仕組み（`mock.js`）と、ジョブごとの決まり（`jobs.js`: ボタンの変化・使える条件・効果・ゲージ・結果の指標）を分けている。効果の多くは説明文から読む（付与・発動条件・与ダメージ上昇・ヘイスト・回復・ゲージの消費） |
| 役割と相方 | 侍: 相方のタンク（出し入れ可）。ナイト: あなたが敵を引きつけ、敵の通常攻撃があなたに来る。相方のヒーラーがときどき回復する。白魔道士: 相方のタンクの HP が敵の通常攻撃で減るので回復する（倒れたらレイズ。20 秒で自分でも起きる）。よけられない全体攻撃も来る。結果に「タンクの HP（平均）」と「タンクの戦闘不能」が出る |
| 設置型の技 | 白魔道士のアサイラム（青白い透明なドーム。15m、3 秒ごとに中の味方を回復、受ける回復 +10%）とリタージー・オブ・ベル（自分の横に生える、水色のガラスのハートと白い花とガラス玉の鈴。自分が攻撃を受けると鈴が 1 つ弾けて 20m を回復、時間切れ・再使用で残りをまとめて回復。再使用はリキャストを待たない）。押すとマウスの位置にターゲットサークルが出て、クリックした所に置く（もう一度押してもマウスの位置に置く。右クリック・Esc でやめる。パッドは自動の場所）。見た目はゲーム内の画面を参考にした光の演出（DESIGN-09） |
| 回復・バリア・軽減 | 説明文から読む: 回復（相手は「対象」= HP の低い方・「自身と周囲」= 全員・「自身の」= 自分）、継続回復、バリア（ディヴァインベニゾン・ディヴァインヴェール）、被ダメージ軽減（アクアヴェール・テンパランス・インドゥルゲンティア・ホーリーシェルトロン）、テンパランスの回復量 +20%、インドゥルゲンティアの追加の回復、ケアルの迅速ケアルラ（15%。ケアルラが光る）、チャージ数。回復は相手の足元に光。MP は未実装 |
| ドット絵 | 画像ファイルなし。図形（楕円・太線・多角形）を組み合わせ、左上からの光で陰影と輪郭を自動で付ける（`sprites.js`）。侍・タンク（ナイト）・白魔道士・からくり木人の 3 方向（左は右の反転）×待機・走り・斬撃・居合の構え・抜刀・詠唱・魔法・被弾・ジャンプ・バフ。自分の見た目はジョブ、相方の見た目は役割で変わる。小物は灯籠・松・岩・柱・崩れた柱・かがり火・草 |
| ステージ | 夜の稽古場（円形・半径 20m）/ 昼の闘技場（四角・40m 四方。床にフィールドマーカー）/ 夕暮れの遺跡（円形・半径 22m）。形と広さで動ける範囲・範囲攻撃の切れ目が変わる。フィールドマーカー（A〜D・1〜4）はどのステージでも出せる。増やすときは `stages.js` に足す |
| 射程と方向指定 | 射程外の技は使えない（アイコンが赤くなる）。月光は背面・花車は側面から（説明文から判定）。敵の足元に背面（緑）・側面（黄）のガイド |
| 敵の範囲攻撃 | 円・ドーナツ・扇・直線・半面・足元の連続円。予兆が満ちると発動し、中にいると被弾（3 回で戦闘不能 3 秒）。敵の詠唱バーと技の予告はターゲット窓に出る |
| タンク | 敵を引きつけ、途中で敵の向きを変えたり移動させたりする（方向指定の取り直し・追いかけの練習）。いない設定にすると敵があなたを追う |
| 先行入力 | そのアクションのリキャストの残りが 0.5 秒以下なら受け付け、使えるようになった瞬間に出す。入れておけるのは 1 つで、先に押したものが優先（後から押したものは無視）。硬直中・詠唱中に押したアビリティは、明けた瞬間に出る。地面指定のアクションは入らない（仮・定説。docs/SPEC.md §6.1） |
| 硬直 | 詠唱のない技 0.6 秒＋応答の遅れ（設定、既定 50ms）、詠唱の後 0.1 秒、夜天 0.8 秒（仮・定説。§6.3） |
| 詠唱と滑り撃ち | 残り 0.5 秒より前に動く（ジャンプを含む）と中断し、GCD は戻る。残り 0.5 秒を切ったら動いても完了（キャストバーの色が変わる）。効果はその時点で決まる。移動中に押すと、詠唱は始まってすぐ中断される。居合術・奥義波切の詠唱は 1.3 秒（特性。仮）（§6.4） |
| ジョブゲージ | クライアントから抽出した ULD とテクスチャ（アトラスのまま）で組み立てる（`uld.js`）。侍: 剣気・剣圧・閃（`gauge.js`）。ナイト: オウスとアイアンウィルの盾、白魔道士: ヒーリングリリー 3 つ・ブラッドリリー（つぼみ → 満開）・リリーの時間（つるが光る）（`gauge2.js`）。ADDON.DAT の配置どおりに置く。通常 / シンプルを切り替え可 |
| ステータス | アイコンは抽出データから名前で引く（無いものは文字の札）。残り秒だけ書き換えるので点滅しない |
| 設定画面 | FF14 のキャラクターコンフィグ風。練習（ジョブ・ステージ・フィールドマーカー・時間・敵の攻撃・相方・ガイド・種・応答の遅れ）/ 操作（カメラの速さ・反転）/ ホットバー・HUD / アクションの変化 / 設定ファイル / 画面（画質）/ 音 / ゲームモード |
| ゲームモード | 全画面にして、Chrome / Edge ではキーボードロックで Ctrl+W・Ctrl+数字・F5・Alt などもゲーム側で受け取る。解除は Esc の長押し |
| 効果音 | Web Audio でその場で合成（ゲームの音声は使わない）。斬撃は風切り＋刀の鳴り、閃の締めは色ごとの鈴、居合術は溜め → 抜刀 → 衝撃、敵の範囲攻撃は予兆と爆発。全体に短い残響 |
| 結果 | 全画面。ランクと点数・大事な数字 4 つ・直すと良いところ。タブでタイムライン（マウスを乗せると詳細）・すべての指標・使ったアクション（回数と与ダメージ）・ミスの一覧。**CSV で保存**（まとめと行動の記録。ゲージの列はジョブごと。Excel で開ける UTF-8） |
| 敵の体力とダメージ | ダメージは説明文の威力 × 与ダメージ上昇（風月など）× 係数。敵の体力は「無限（木人）/ 決める / 前回の与ダメージ」。0 で撃破して終わり、撃破時間が出る。フライテキストに技名とダメージ（英数字は Cinzel、日本語は明朝） |
| マクロ | 設定 → 設定ファイルで MACRO.DAT（共通マクロは MACROSYS.DAT）を読むと、ホットバーのマクロが `/ac` の行のアクションを使うボタンになる（右上に「M」）。待ち（`/wait`・`<wait.N>`）・対象（`<me>` `<2>` `<mo>`＝パーティリストのマウスを乗せた行）・地面指定（`<me>` `<t>` `<mo>`）に対応。先行入力はされない。題名と文の中身はブラウザにも保存しない |
| HUD の配置 | ADDON.DAT の識別値で部品を特定し、キャストバー・ターゲット情報（まとめ / 分割）・パラメーターバー（HP・MP）・ステータス情報（まとめ / 分割）・パーティリスト・ジョブゲージ・ホットバーをあなたの HUD の位置に置く。部品は等倍で組んで HUD の倍率を掛けるので、小さくしても文字がぼやけない。設定で「枠を表示」すると部品の名前と枠が出る |
| タンクの腕前 | 上手（すぐよけて敵の向きを変えない）/ ふつう / 下手（よけるのが遅く、向きがふらつく） |
| 動作確認用 | URL に `?speed=4` のように付けると時間が速く進む。コンソールから `MockDebug` で状態を見られる |

## モックの割り切り（本実装とは違うところ）

- 硬直 0.6 秒＋応答の遅れ、先行入力 0.5 秒、コンボ受付 30 秒、剣気の上限 100 は**仮の値**（GAME-04〜06, 12。硬直と先行入力はコミュニティの解析の定説）。移動速度・当たり判定・近接の射程・方向指定の角度・滑り撃ちの猶予も**仮**（GAME-50〜55。設定 → 練習に一覧）。
- ナイト・白魔道士の、説明文から読めない決まり（レクイエスカットの減り方・オウスとリリーの増え方・コンフィテオル以降のコンボ）と、居合術の 1.3 秒は**仮**（GAME-60〜64）。敵の攻撃力・回復量の換算・相方の動きは練習用（DESIGN-06・07）。
- 移動はレガシーに近い動き（押した方向へ走る）。スタンダード（左右キーで旋回）は未対応（GAME-57）。カメラの初期値と速さはモックの操作感（DESIGN-05）。ステージは練習用に作った場所（DESIGN-04）。
- 敵の範囲攻撃とタンクの動きは練習用に作ったもので、ゲームの特定の敵の技ではない（DESIGN-02）。
- ジョブゲージの光り方は仮（ULD のタイムラインを未抽出。UI-01）。
- 黙想は、剣圧を即座に 3 にする簡易版。プリプルで使えるのは明鏡止水・トゥルーノース・アイアンウィル・迅速魔だけ（GAME-30 未確認のため、自分にかけるものだけ）。
- 実機はフレームの遅れ（使えるようになった次のフレームで出る）で GCD が少し伸びるが、練習では入れていない。
- クロスホットバーのスロット番号とボタンの対応は仮（CFG 未確認）。
- どのバーが共有かは推定（CFG-08）。アクションの変化の設定も推定＋手動（CFG-11）。
- 採点は一部の項目だけ。お手本（開幕回し）は未実装。
- 判定は `requestAnimationFrame` の中で行っており、本実装の「決定的なエンジン」（STATE_MACHINE.md）ではない。

## サーバー（nettoge.com）に仮で置く

`.github/workflows/deploy-mock.yml` が、`mock/` などを変更して push したとき（または Actions 画面で「Run workflow」を押したとき）に動きます。

1. **必ず作られるもの:** Actions の実行結果ページの下にある成果物 **`mock-site`**（zip）。中身をサーバーの好きな場所にアップロードすれば、そのまま動きます（`index.html` を開くだけ。サーバー側の設定は不要）。
2. **自動でサーバーへ送る場合:** GitHub のリポジトリ設定 → **Settings → Environments → New environment** で `mock` を作り、次を登録します（値はチャットやコードに書かないでください）。

| 種類 | 名前 | 内容 |
|------|------|------|
| Secret | `DEPLOY_HOST` | サーバーのホスト名または IP |
| Secret | `DEPLOY_PORT` | SSH のポート（22 なら省略可） |
| Secret | `DEPLOY_USER` | アップロード用のユーザー |
| Secret | `DEPLOY_SSH_KEY` | そのユーザーの秘密鍵（アップロード専用に作った鍵を推奨） |
| Secret | `DEPLOY_KNOWN_HOSTS` | `ssh-keyscan -p <ポート> <ホスト>` の出力（指紋を確認したもの） |
| Variable | `DEPLOY_MOCK_PATH` | 置き場所のフォルダ（例 `/var/www/html/tools/ff14-rotation-trainer-mock`）。**中身は毎回入れ替わる**ので専用のフォルダにする |
| Variable | `MOCK_URL` | 公開 URL（例 `https://nettoge.com/tools/ff14-rotation-trainer-mock/`）。送信後の確認に使う（省略可） |

- Secrets が未登録のときは、送信を省略して警告を出すだけです（zip は作られます）。
- 仮の公開なので、`noindex` と `robots.txt` で検索エンジンに載らないようにしています。
- SSH を特定の IP に制限している場合、GitHub Actions からは接続できないことがあります（docs/DEPLOY.md §4.3）。そのときは zip を手でアップロードしてください。
